BigBrain System Visualizer

A Mac app that shows a software system as a map anyone can walk, built and kept current by your own coding agent. The demos, the viewers, and inspecting a file someone sent you are free. A system of your own is a subscription; the demo shows every feature before you decide.

Download for Mac
What it is

Your system, as a map a non-programmer can walk.

BigBrain System Visualizer, BigBrain Visualizer for short, shows a software system as a 3D map: its parts, the connections between them, and the scenarios that run through them, laid out so that someone who does not read code can follow what the system does. Your own coding agent, Claude Code or GitHub Copilot, reads the code, builds the map, answers questions about it, and keeps it current as the code changes. Nothing is sent to us: the code stays in your checkouts, the agent runs under your own account, and everything BigBrain learns is kept in a folder on your Mac.

An inspection lets a group walk the system together, leave comments and To Do's on the map, mark what they have checked, and close with a report. A specialist outside the team is sent a file instead: they open it for free, walk it, play its scenarios with narration, and send their notes back. The free headset viewer opens the same file on Apple Vision Pro, so a system can be walked in a room rather than on a screen.

Download

Free to download. The demos run with no sign-in.

Pick the build for your Mac. Apple silicon is any Mac with an M series chip; Intel is any Mac from before. Unzip the file and drag the app to Applications. Each build is signed and notarized, and the app updates itself from then on.

Requirements. BigBrain Visualizer is a Mac app only, for macOS 15 or later. To build a system of your own it needs a coding agent, Claude Code or GitHub Copilot, installed and signed in on the Mac. The demos and sent files need neither an agent nor an account.

Not sure which Mac you have? Choose About This Mac from the Apple menu: a chip beginning with M is Apple silicon, and a processor from Intel is Intel.
